## Assignment Features Included

- **Profile hero with layered decorative shapes:** Crafted with `position: relative`, `position: absolute`, and `z-index`.
- **Three rounded card styles:** Light, dark (`.card-dark`), and accent (`.card-accent`).
- **Sticky navigation & fixed button:** Sticky top navigation bar (`position: sticky`) and a floating back-to-top button (`position: fixed`).
- **Bounded notes panel:** Smooth scrollable container with `overflow: auto`.
- **Responsive horizontal tile strip:** Projects strip whose overflow stays cleanly inside its panel with horizontal scrolling.
- **Annotated CSS Box Model:** Visual illustration showing `content`, `padding`, `border`, and `margin`.
- **Responsive Layout:** Mobile and tablet layouts using `box-sizing: border-box` globally.
